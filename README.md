# Vector Systems Group LLC — Static Site

This is a simple, mobile-friendly one-page static website for **Vector Systems Group LLC**, intended to be hosted on **GitHub Pages**.

## Files

- `index.html` — page content
- `styles.css` — styling
- `assets/vector_systems_group_logo.svg` — logo
- `assets/us-government.jpg` — representative photo
- `assets/facilities-support.jpg` — representative photo
- `assets/environmental-field.jpg` — representative photo

## Publish on GitHub Pages

1. Create a new GitHub repository (public).
2. Upload these files to the repository root (or push via git).
3. In GitHub:
   - Go to **Settings ? Pages**
   - **Build and deployment**
     - Source: **Deploy from a branch**
     - Branch: `main` (or `master`) / `(root)`
4. Wait ~1–2 minutes for the site to deploy.

## Update contact details

Edit `index.html` to change phone/email/address or the identifiers shown in the header/footer.
